# Platform Adapters & Path Resolution

## Platform Targets & Cross-Platform Path Mapping

SaveSync runs across Windows 11, CachyOS, and Bazzite (Linux/Steam Deck/Handhelds).

### Path Placeholders & Environment Expansion
Paths reported by Ludusavi or user input contain system placeholders that MUST be expanded deterministically:
- Windows: `%APPDATA%`, `%LOCALAPPDATA%`, `%USERPROFILE%`, `%PROGRAMFILES%`, `%SAVEDGAMES%`
- Linux / Proton / Wine:
  - `$HOME`, `~`, `$XDG_CONFIG_HOME`, `$XDG_DATA_HOME`
  - Steam Proton prefixes: `<SteamLibrary>/steamapps/compatdata/<appid>/pfx/drive_c/users/steamuser/`

## Adapter Interface (Rust Concept)

```rust
pub trait SaveLocationAdapter: Send + Sync {
    /// Unique identifier for this location type
    fn adapter_type(&self) -> &'static str;
    
    /// Resolve physical filesystem paths for current OS
    fn resolve_paths(&self) -> Result<Vec<PathBuf>, AdapterError>;
    
    /// Check if target save files exist and are readable
    fn exists(&self) -> bool;
    
    /// Collect current files and calculate SHA-256 manifest
    fn capture_manifest(&self) -> Result<FileManifest, AdapterError>;
}
```

## Adapter Implementations

1. **LudusaviPCAdapter**: Executes `ludusavi --api api backup --preview --game <Name>` or parses Ludusavi database manifests to discover store paths (Steam, GOG, Epic, Ubisoft, Microsoft Store).
2. **CustomDirectoryAdapter**: Resolves user-configured direct directory paths or file glob patterns.
3. **EmulatorAdapter**:
   - **PCSX2 / DuckStation**: Memory card images (`.ps2`, `.mcd`) or directory saves (`sstates`, `memcards`).
   - **RPCS3 / Ryujinx / Yuzu / Dolphin**: Virtual save directories mapped under `dev_hdd0/home/...` or `nand/user/save/...`.
4. **JKSVExportAdapter**: Handles Nintendo Switch save folder exports generated by JKSV (`/JKSV/<Game>/<Timestamp>/`).
